Prompt differences:
1. **Grader framing.** An empty diff scores zero; a correct diff scores even if the local test is red.
2. **Contract before any tool call.** List the exact symbols, strings, status codes and return values, and copy them
   verbatim.
3. **Locate in a few reads.** One `git grep`, then one `read_file` range of at most 120 lines, plus one follow-up at
   most. R017 allowed "about 10 calls" of reading.
4. **Same edit-by-call-12 rule.** New: create new files only if the issue requires one; never touch `pytest.ini` or
   `conftest.py`; **scratch scripts go in /tmp**.
5. **One check, one repair, then submit even when red.** R017 said submit "once your targeted test passes".
   `git checkout --` test paths; submit if `get_status` shows < 90 s left.
6. Removed: R017's long "targeted tests only" section and the graph-tool warning.

R017's fallback bullet has no counterpart in the reference.

## 4. R017 failure evidence (traces; `evaluations/analysis/R018_r017_trace_analysis.md`)

**R017's 11 unresolved tasks:**
- **No edit (6).**
  - 3 queued a complete edit at call 29–30 that the cap refused: fastapi_14873, fastapi_15589, rich_3470.
  - rich_3063 resent the same malformed `edit_file` 9 times.
  - rich_3105 searched in circles on a "Fix #3104" issue.
  - rich_3180 timed out.
- **Wrong fix (5).**
  - Partial: rich_3061, whose first edit came at call 25.
  - Contract the issue never states: rich_3052 (canonical return value) and rich_3468 (exit code 1).
  - Wrong cause: rich_3471.
  - Out of budget mid-fix: rich_3480, `append` fixed and `append_text` not, after 6 malformed edits.
- **Edit timing.** 1 of 11 failures had edited by call 12, against 8 of 13 resolved tasks. Median first edit:
  call 12 (resolved) vs 16 (wrong fix).

**Malformed `edit_file`.**
- 21 of 54 R017 calls came out with filepath + new_string only, with code fragments as stray keys.
- google-adk replies "Invoking `edit_file()` failed as the following mandatory input parameters are not present:
  old_string".
- R017's bullet fires on "old_string not found", so the fallback ran once in 24 tasks.
- Single-string tools never malformed:
  - `write_file`: 0 of 71 calls in R016+R017 with code payloads;
  - `run_command`: 0 of 99 heredoc/code payloads.
  - The code-edit `replace` route (heredocs to /tmp) is therefore a working channel.

**Post-edit testing.**
- A check after the final edit would plausibly have caught 1 of the 5 wrong fixes (rich_3468, whose output still showed
  BrokenPipe).
- In the other 4, a post-edit check had already passed, or the agent's own test asserted the wrong behaviour.
- **A mandatory testing workflow is therefore not the lever,** and the reference also limits testing to one check.

**Scratch files.** They are in 10 of 24 patches, but 4 of those resolved. They are hygiene, not the deciding factor.

**Ranking of the candidate causes:**
1. late or lost edits, including malformed edits (7 of 11);
2. the issue's contract being under-specified (≥ 3, and not fixable by prompting);
3. incomplete edits (2);
4. scratch files (0 outcome-deciding).

The prompt difference (§3) addresses (1) through the "locate in a few reads" limit and (4) through the /tmp rule. The
corrected fallback addresses the malformed-edit part of (1). Neither part is new machinery: the prompt is the
reference's bytes, and the fallback is R017's own bullet, which as written never fired on the error that occurs.

## 6. Pre-registered gate (recorded before any R018 result exists)

The same 24 tasks, order and gold control as R015–R017, on the official swegemma Evaluator in the same notebook. R018
runs as the first variant, as R017 did.

**R018 passes only if all of:**
1. **≥ 15/24 resolved.**
2. **wins − losses ≥ 3 vs R017** (paired per task).
3. **No material increase in wrong patches or regressions:** wrong fix (edited, unresolved) ≤ 5 (R017: 5) **and**
   paired losses vs R017 ≤ 2.
4. **Fewer incomplete repairs and inappropriate file changes:**
   - (a) patches containing non-source scratch files < 10 (R017: 10);
   - (b) patches touching test files ≤ R017's count;
   - (c) incomplete repairs ≤ 1 (R017: 2, rich_3061 and rich_3480). Incomplete means partial vs gold, or ended at a
     budget limit mid-fix, classified the same way as the R017 analysis.
5. **No harness or tool-contract failures:**
   - 0 vLLM / sandbox / harness errors;
   - no session ended by a tool-contract error;
   - no call to an unregistered tool that is not returned as a recoverable error.
6. **Runtime:** projected full run (agent phase per task × 120 + 15 min) ≤ 10.5 h.

Reported but not gated:
- malformed `edit_file` count and fallback uses;
- first-edit call;
- post-final-edit test coverage;
- call-cap and timeout hits;
- duration mean and median.

**Same-kernel R017 replicate (noise check, not part of the gate).** The kernel then runs the unchanged R017 archive
(`51a6ef89…`) as a second variant on the same tasks and server. It measures run-to-run variation, so an R018 difference
can be read against it. The gate is applied against the stored R017 run, as pre-registered. If the replicate
contradicts the stored R017 result, that is reported, and the gate is not reinterpreted.

A local 15/24 does not imply a public 0.22. If R018 fails the gate, the evidence is documented and work stops: no R019.
