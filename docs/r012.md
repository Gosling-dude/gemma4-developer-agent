# R012-v13-handoff: read-only localization handoff before the V1.3 coder (Phase 1 build, not run)

**Hypothesis (one):** a forced, read-only localization stage whose short plan seeds the coder lowers wrong-file /
wrong-fix failures (class B = 19 of 38 valid real-Gemma failures, R004–R011) and so raises resolution. R010 showed
a prompt-only diagnosis rule is ignored (0/12 compliance); here the stage is structural.

`submission/r012-v13-base/submission.zip`). R010's diagnosis rule is not included.

Harness facts that shaped it (official swegemma 0.2.7 / google-adk 1.36.1 source):
- An undeclared tool call raises `ValueError` (no callback catches it) and ends the task, so the localizer keeps
  every tool the harness prompt names (graph tools) and gets no write tools; its prompt names none of the absent ones.
- `include_contents: none` starts the coder at the localizer's final reply: the coder does not carry the localizer's
  tool output or the harness's first message (budget lines, environment rules, workspace tree); the issue reaches it
  through `{problem_description}`.
- A harness nudge (turn ended without `submit_patch`) re-runs the whole sequence (a sub-agent of a SequentialAgent
  is not resumable). The localizer then repeats its plan (1 LLM call, no tools), but the coder restarts without its
  earlier history (its edits stay in the tree). Nudges: 0 of 30 tasks in R008–R010.
